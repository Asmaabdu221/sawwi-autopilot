# سوّي أوتوبايلوت

**نظام محتوى يومي يشتغل على جهازك.**
يلتقط الأفكار من القنوات التي تتابعها، يكيّفها لبراندك وجمهورك، وينتج حزمة نشر كاملة — نصًّا صوتيًا وستة كابشنات وغلافًا.

**بلا مفتاح API. بلا اشتراك شهري. يشتغل باشتراك Claude الذي عندك.**

</div>

**🔗 صفحة المشروع:** https://asmaabdu221.github.io/sawwi-autopilot

## وش يسوي بالضبط

```
كل صباح
  ① يقرأ قنوات مراجعك ويتجاهل الأخبار والمحتوى السطحي
  ② يحوّل كل فيديو إلى ١–٣ أفكار مكيّفة لبراندك وسوقك المحلي
  ③ يمنع التكرار — بتطبيع عربي ومقارنة دلالية
  ④ يحفظها في بنك أفكار تراجعه وتعتمد منه
  ⑤ يحوّل الفكرة المعتمدة إلى حزمة جاهزة للتصوير
```

**الحزمة الواحدة تحتوي:** ٣ خطّافات · نص صوتي ٤٥ ثانية · جدول مشاهد · رقاقة «قبل ← بعد» · حكم صريح · كابشن مستقل لتيك توك وإنستقرام وشورتس وسناب وإكس ولينكدإن (عربي وإنجليزي) · نص الغلاف.

## ليش يختلف عن «اكتب لي منشور»

| أدوات المحتوى المعتادة | سوّي أوتوبايلوت |
|---|---|
| تكتب من فراغ | يبدأ من فكرة مأخوذة من مراجع مجرّبة |
| نفس النص لكل المنصات | ستة كابشنات مستقلة بحدود كل منصة |
| تقبل أي مخرَج | **حارس براند** يرفض ما يخالف قواعدك قبل أن تراه |
| تكرر نفسها | **بنك أفكار** يمنع التكرار ويتذكر ما رفضته |
| تخترع أرقامًا | يطلب منك التجربة ويضع مكان رقمك الحقيقي |

## التثبيت

### المتطلبات
| | |
|---|---|
| **Node.js 20+** | [nodejs.org](https://nodejs.org) |
| **Claude Code** | `npm install -g @anthropic-ai/claude-code` ثم `claude` وسجّل الدخول باشتراكك |

### التشغيل
```bash
npx sawwi-autopilot
```

أو بالتحميل المباشر:
```bash
git clone https://github.com/Asmaabdu221/sawwi-autopilot.git
cd sawwi-autopilot
node setup.mjs
```

المثبّت يسألك عن براندك وجمهورك ومراجعك، ويبني لك دماغ براند خاصًا بك.

### جرّب فورًا — بلا أي إعداد إضافي
```bash
node scripts/wf1-ideas.mjs --days 14 --limit 2 --dry-run
```
يلتقط فيديوهين من مراجعك ويطبع الأفكار المكيّفة على الشاشة. **لا يحفظ شيئًا** — فقط لترى الجودة.

## الأسئلة المتكررة

<div align="right">

**هل أحتاج مفتاح Anthropic API؟**
لا. النظام يستدعي `claude -p` الذي يستخدم تسجيل دخولك بالاشتراك. إن كان `ANTHROPIC_API_KEY` مضبوطًا في بيئتك فسيُستخدم بدلًا منه وتُحاسَب عليه — احذفه إن لم ترد ذلك.

**هل يشتغل والجهاز مغلق؟**
لا في المستوى المحلي. الجدولة تعيد المحاولة عند أول تشغيل، ونافذة البحث سبعة أيام فلا تضيع فكرة.

**هل ينشر تلقائيًا؟**
لا في هذه النسخة. ينتج ويسلّم — والنشر بيدك. وهذا مقصود: تراجع قبل أن يخرج باسمك.

**هل ينسخ محتوى المراجع؟**
لا. يستخرج الفكرة والبنية ثم يعيد بناءها بلغتك وسوقك ومثالك المحلي، ويطلب منك تجربة حقيقية قبل أي رقم.

**بأي لغة؟**
مبني للعربية أولًا — تطبيع عربي في منع التكرار، وقوالب سعودية وخليجية. يعمل بأي لغة بتعديل ملفات `brain/`.
