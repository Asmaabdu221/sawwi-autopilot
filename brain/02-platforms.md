# المنصات — المواصفات وأوقات النشر
> التوقيت: **توقيت الرياض (UTC+3)**. الأسبوع السعودي: الأحد أول أيام العمل، الجمعة والسبت إجازة.

## جدول النشر اليومي
| المنصة | الوقت | الأيام | الصيغة الأساسية |
|---|---|---|---|
| **تيك توك** | ٢٠:٠٠–٢٢:٠٠ | يوميًا | فيديو عمودي ٩:١٦ |
| **إنستقرام ريلز** | ٢٠:٣٠–٢٢:٠٠ | يوميًا | نفس الفيديو + غلاف كامل |
| **إنستقرام كاروسيل** | ١٩:٠٠ | ٢–٣ مرات أسبوعيًا | ١٠٨٠×١٣٥٠ |
| **يوتيوب شورتس** | ٢٠:٠٠ | يوميًا | ≤ ٦٠ ثانية |
| **يوتيوب طويل** | ١٩:٠٠ | الخميس | ٨–٢٥ دقيقة — «نبني نظامًا كاملًا» |
| **سناب شات** | ٢١:٠٠ | يوميًا | Spotlight + ستوري البروفايل |
| **لينكدإن** | ٠٨:٠٠–١٠:٠٠ | الأحد · الاثنين · الثلاثاء | نص أو كاروسيل PDF أو فيديو أصلي |
| **إكس** | ١٢:٠٠–١٣:٠٠ | يوميًا | سطر واحد أو ثريد |

**قاعدة ثابتة:** الرد على كل تعليق في أول ساعة من النشر. هذا ليس اختياريًا — هو نصف الخوارزمية.

## الحدود الفنية
| المنصة | الكابشن | الهاشتاقات | الفيديو | ملاحظة |
|---|---|---|---|---|
| تيك توك | ٢٬٢٠٠ حرف (نستهدف ≤ ٣٠٠) | ٣–٥ | ٩:١٦ · ٢١–٦٠ث | أول سطرين فقط يظهران |
| إنستقرام | ٢٬٢٠٠ حرف (نستهدف ≤ ٤٠٠) | ٥–٨ (حد ٣٠) | ٩:١٦ · ≤ ٩٠ث للريلز | أول ١٢٥ حرفًا قبل «المزيد» |
| يوتيوب شورتس | عنوان ١٠٠ · وصف ٥٬٠٠٠ | ٣ في الوصف | ≤ ٦٠ث رأسي | العنوان هو الخطّاف |
| سناب شات | نص قصير على الشاشة | — | ٩:١٦ · ≤ ٦٠ث | **بلا API نشر عام — يُنشر يدويًا** |
| لينكدإن | ٣٬٠٠٠ حرف (نستهدف ٧٠٠–١٬٣٠٠) | ٣–٥ | ≤ ١٠ دقائق | أول ٣ أسطر قبل «See more» |
| إكس | ٢٨٠ حرفًا (بريميوم أطول) | ٠–٢ | ≤ ٢:٢٠ | الهاشتاقات تضعف الوصول — قلّلها |

> ⚠️ راجع هذه الحدود كل ٣ أشهر — المنصات تغيّرها بلا إعلان.

## قابلية النشر الآلي — الوضع الحقيقي
| المنصة | نشر آلي؟ | الطريق |
|---|---|---|
| إنستقرام | ✅ | Graph API لحساب Business + Creator — عبر طبقة نشر |
| يوتيوب | ✅ | YouTube Data API v3 (رفع مباشر) |
| لينكدإن | ✅ | نشر شخصي عبر `w_member_social` أو عبر طبقة نشر |
| إكس | ✅ | X API v2 |
| تيك توك | ⚠️ | Content Posting API — **النشر المباشر يحتاج تدقيق التطبيق**. بدونه يصل كمسودة في صندوق الوارد وتضغط «نشر» من الجوال |
| **سناب شات** | ❌ | **لا يوجد API نشر عضوي للمبدعين.** الأتمتة تجهّز الملف والنص وترسلهما لجوالك، والنشر بضغطة يد |

**الاختيار المقترح لطبقة النشر:** Blotato (نفس ما يستخدمه المرجع) أو Ayrshare — واحدة منهما تغطي إنستقرام ويوتيوب ولينكدإن وإكس وتيك توك بمفتاح واحد بدل ستة تطبيقات مطوّر. سناب يبقى يدويًا في الحالتين.

## إعادة الاستخدام — أصل واحد ← ٧ مخرجات
كل يوم ننتج **قطعة واحدة** ثم نشتقّ منها:
1. **الفيديو الرأسي** (الأصل) → تيك توك · ريلز · شورتس · سناب — بكابشن مختلف لكل منصة، **لا تُنسخ كما هي**
2. **الكاروسيل** → إنستقرام + PDF للينكدإن
3. **النص المهني** → لينكدإن (زاوية صاحب القرار: التكلفة، الفريق، العملية)
4. **السطر الواحد** → إكس (أقوى جملة من النص الصوتي)
5. **الخميس:** الأربعة الأصول تُجمع في فيديو يوتيوب طويل «النظام كاملًا»
